# Checklist Uji Manual Workspace Input Minimum

Jalankan `npm.cmd run dev`, lalu gunakan proyek uji terpisah di browser. Isi seluruh sumber/penginput wajib dan pilih sistem struktur ALLOWED sebelum memeriksa hasil M6 atau mengekspor DOCX. Nilai contoh di bawah mengikuti fixture/test aplikasi. Checklist ini belum dijalankan; isi Hasil dengan LULUS/GAGAL dan catatan setelah uji.
